# Plant App Widget

A lightweight desktop widget application built to help you track and manage your plants.

## Tech Stack

* **Frontend:** Pure HTML, CSS, and JavaScript
* **Backend:** Tauri

## Development Setup

### Prerequisites

* Node.js
* Rust and Cargo
* Tauri CLI

### Running Locally

1. Install project dependencies:

```bash
npm install

```

2. Start the development server and open the widget:

```bash
npm run tauri dev

```

### Packaging

To build a standalone executable for your current operating system:

```bash
npm run tauri build

```
